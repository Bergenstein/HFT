HOW TO TEST EACH COMPONENT:
---

1. SCAN DATA FILE
   Command: ./build/scan_recording <data_file.ndjson>
   Example: ./build/scan_recording data/raw_20251107_194636_ws0.ndjson
   
   Output: Shows all products and update counts in the file

2. REPLAY ORDER BOOK
   Command: ./build/replay_and_book <data_file.ndjson> <PRODUCT-ID>
   Example: ./build/replay_and_book data/raw_20251107_194636_ws0.ndjson LTC-EUR
   
   Output: Prints best bid/ask as book updates

3. MEASURE LATENCY
   Command: ./build/complete_latency_test <data_file.ndjson> <PRODUCT-ID>
   Example: ./build/complete_latency_test data/raw_20251107_194636_ws0.ndjson LTC-EUR
   
   Output: 
   - Parse latency: ~13.85μs average (JSON parsing)
   - Book update: ~0.03μs average (order book maintenance)
   - Total: ~13.93μs average end-to-end
   
   YOUR SYSTEM PROCESSES EACH MESSAGE IN 14 MICROSECONDS!

4. BACKTEST STRATEGY
   Command: ./build/backtest_strategy <data_file.ndjson> <strategy> <PRODUCT> <qty> <param1> <param2> <capital>
   Example: ./build/backtest_strategy data/raw_20251107_194636_ws0.ndjson imbalance LTC-EUR 0.1 0.6 5 10000
   
   Available strategies:
   - imbalance          (params: threshold, hold_seconds)
   - ofi                (params: decay, threshold)
   - microprice         (params: threshold, hold_seconds)
   - quote_intensity    (params: window, threshold)
   - spread_reversion   (params: threshold_mult, hold_seconds)
   - vpin               (params: num_buckets, threshold)
   - vw_spread          (params: threshold, hold_seconds)
   
   Output: Full P&L report with Sharpe ratio, drawdown, fees, etc.

5. COLLECT LIVE DATA
   Command: ./build/stream_and_record
   
   Output: Creates data/raw_<timestamp>_ws0.ndjson files
   Press Ctrl+C to stop

6. TEST ZEROMQ PUB/SUB (Advanced)
   Command: ./build/test_zmq_pubsub
   
   Output: Demonstrates distributed messaging between components
   Tests Protocol Buffer serialization over ZeroMQ
